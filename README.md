# Data-Quality-for-Reserving

This repository contains code samples and datasets for the Data Quality and Validation for Reserving Data Pipelines paper. Examples are intended to be used solely for illustrative purposes. Example datasets may not resemble "real" data. The source of the original datasets is provided below, where available. Datasets may have been modified or adjusted to better demonstrate realistic data quality issues and concepts.

<code>policy_details.parquet</code> and <code>claim_details.parquet</code> were adapted from [this Kaggle dataset](https://www.kaggle.com/datasets/jhasony/privateinsurancedata/data).

<code>insurance_claims_ncap.csv</code> and <code>insurance_claims_ncap.parquet</code> was adapted from [this Kaggle dataset](https://www.kaggle.com/datasets/mustakimkureshi/dataset-car-insurance-claim/data).

<code>insurance_claims_info.csv</code> and <code>insured_info.csv</code> were adapted from [this source](https://data.mendeley.com/datasets/992mh7dk9y/2).
